# bold-legal

Public legal pages for the Bold dating application — hosted via GitHub Pages.

## Pages

- **Home** — `index.html`
- **Terms of Service** — `terms.html`
- **Privacy Policy** — `privacy.html`
- **Community Guidelines** — `community.html`

## Hosted URL

Once GitHub Pages is enabled, content is available at:

- https://bold-dream.github.io/bold-legal/
- https://bold-dream.github.io/bold-legal/privacy.html ← used in Google Play Console
- https://bold-dream.github.io/bold-legal/terms.html
- https://bold-dream.github.io/bold-legal/community.html

## Updating

Edit the relevant `.html` file and push to `main`. GitHub Pages redeploys automatically (typically within a minute).

The in-app version of these documents lives in [`bold-mobile-native/app/terms-privacy.tsx`](https://github.com/Johnmuchiri/bold-mobile-native/blob/main/app/terms-privacy.tsx) — keep both in sync when making changes.
